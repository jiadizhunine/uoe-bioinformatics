## 先看这几条

- **不是学校官方指南，也不是学生口碑调查。** 1–5 分难度由 LLM 判断，不能预测成绩；基础、兴趣和实际授课安排都会改变体验。
- **MATH11205 Machine Learning in Python：本版建议不选。**
- **有笔试不一定更难，无笔试不一定省力。** 实验、团队项目和长报告的时间成本同样重要。
